I host **.NET in pillole**, an Italian podcast dedicated to .NET and software development.

Each episode starts from something concrete: a technology, a tool, a new feature or a problem that developers can encounter in their daily work.

- ASP.NET Core
- Blazor
- software architecture
- developer tools
- AI for developers
- libraries and frameworks
- performance and testing
